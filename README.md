# soalindo

Projeto de portfólio pessoal com PHP, HTML, CSS e JavaScript.

## Estrutura organizada

```text
soalindo/
├── README.md
├── index.php
├── sobre.php
├── contato.php
├── assets/
│   ├── css/
│   │   └── estilo.css
│   ├── js/
│   │   └── script.js
│   └── img/
├── config/
│   └── conexao.php
├── database/
│   └── banco.sql
├── pages/
│   ├── home.php
│   ├── sobre.php
│   └── contato.php
└── public/
    └── (opcional para arquivos públicos futuros)
```

## Como usar

1. Crie o banco com o arquivo `database/banco.sql`.
2. Ajuste as configurações do banco em `config/conexao.php`.
3. Abra o projeto em um servidor local (XAMPP/WAMP/LAMP).
4. Acesse `index.php` ou os arquivos em `pages/`.

## Observação

Os arquivos antigos foram preservados para compatibilidade, mas a estrutura principal foi reorganizada para facilitar manutenção.
